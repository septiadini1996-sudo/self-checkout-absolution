A short rant for the Angry Judge contest: the self-checkout scans your bananas, freezes, summons a human to accuse you of stealing them, then forgives you on the spot. The program writes the rant (under the 400-character cap) to /output/entry.txt.

## Run it

```sh
python3 main.py
```
